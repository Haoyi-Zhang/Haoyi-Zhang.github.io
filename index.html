Research

A common question across my work: what can we check before we trust a software change?

  1. 01

    Program analysis and software security

    I use program analysis and executable checks to study authorization rules, security patches, and what changes when a program is run in a different context.

    Related work ↓
  2. 02

    AI-assisted software development

    I am interested in how developers can trace, test, and review AI-generated changes, including automated repairs and code provenance.

    Related work ↓
  3. 03

    Software compliance and evaluation

    I build benchmarks that make compliance claims testable and examine where automated methods miss violations in real software.

    Related work ↓
