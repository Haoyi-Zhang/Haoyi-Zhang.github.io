Academic homepage

Haoyi Zhang

Software analysis, security, and AI-assisted development

I study how to check what software actually does. I am interested in whether code follows access rules, whether a security patch breaks legitimate behavior, and what evidence makes AI-generated changes easier to review.

Research

I use program analysis, benchmarks, and executable checks to find out what software does and where its guarantees fall short.

  1. 01

    Software security and program analysis

    How can we recover useful security specifications when the code is all we have?

    • SPECTRA
    • WasmCert
  2. 02

    AI-assisted software engineering

    What can provenance tell us about a generated change, and what still needs testing?

    • The Watermark Paradox
    • Who Wrote This Patch?
  3. 03

    Software compliance and evaluation

    What do language models and static analyzers miss when they look for violations in real Android code?

    • GDPR-Bench-Android
    • Android compliance study
  4. 04

    Systems and verification

    What evidence can we provide about the behavior of systems when execution order or shared state matters?

    • RaceCert
    • Way Masks Are Not Isolation
