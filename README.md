# Haoyi Zhang · Academic homepage

This repository serves a bilingual static homepage through GitHub Pages. Edit
`content.cjs` for profile text and references or `assets/homepage.css` for styling.
Regenerate the HTML with:

```sh
node build-homepage.cjs
node test-homepage.cjs
```

The generated English and Chinese pages work without client-side JavaScript.
Only public-profile material belongs in this repository.
Keep published citations, public manuscripts, research talks, and SRC decisions
separate. An accepted abstract does not establish attendance, an award, or
publication. Link to public artifacts without copying private certificates,
decision notices, or anonymous submissions into this repository.
